# BAISHI — сайт с админкой для фото

## Настройка (один раз, ~10 минут)

### 1. GitHub
- github.com → **New repository** → имя `baishi-website`, тип **Public** → Create
- Загрузите СОДЕРЖИМОЕ этой папки (не саму папку): index.html, about.html, admin/, images/, content/, PDF-файлы

### 2. Указать свой репозиторий
Откройте `admin/config.yml`, строка 3:
```
repo: ЗАМЕНИТЕ/НА-СВОЙ-РЕПОЗИТОРИЙ
```
замените на свой, например: `repo: ivan-baishi/baishi-website`

### 3. Подключить Netlify к GitHub (важно!)
Netlify → **Add new site** → **Import an existing project** → **GitHub** → выберите `baishi-website`
- Build command: пусто
- Publish directory: пусто (или `.`)
- Deploy

> Теперь сайт обновляется САМ при каждом изменении через админку.
> Старый сайт, залитый перетаскиванием, так работать не будет.

### 4. Включить вход в админку
Netlify → **Site configuration → Access & Identity → OAuth → Install provider → GitHub**

---

## Как менять фото

1. Откройте `ваш-сайт.netlify.app/admin/`
2. **Login with GitHub**
3. Раздел **«Фотографии сайта» → «Все фото»**:
   - **1. Карточки товаров** — 4 главные фото категорий
   - **2. Альбом** — галереи по вкладкам (добавлять / удалять / менять порядок)
   - **3. Страница «О компании»** — цех, контейнеры, клиенты, команда, тимбилдинг, склад
4. **Save** → через ~1 минуту сайт обновится

## Рекомендуемые размеры фото
- Карточки товаров: ~900×720 px
- Альбом: ~820×540 px
- О компании: ~1200×900 px

## Что админка НЕ меняет
Тексты, языки, вёрстку — это защита от случайной поломки. Нужны правки текста — пишите разработчику.
